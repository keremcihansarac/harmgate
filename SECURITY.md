# Security

Please report security problems privately through **Report a vulnerability** on this repository's [Security tab](https://github.com/keremcihansarac/harmgate/security), not in a public issue.

Useful things to report:

- A way for a web page to read or change Harmgate's settings
- A way for a downloaded list to do anything other than block domains
- A problem in how releases are built

A way around the filter, such as a site missing from a list, is not a security problem. Please open a normal issue for those.

Harmgate is maintained by one person in their spare time, so replies may take a while. Only the latest release gets fixes.
